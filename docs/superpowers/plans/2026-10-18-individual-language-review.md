# Einheitliche Texte im Individualtraining

Ziel: Trainer und Spieler erhalten verständliche deutsche Texte in der Du-Anrede. „Individualtraining“, „Trainer“, „Spieler“, „Rückmeldung“, „Trainingsplan“, „Tagesform“ und „Wochenfokus“ sind die verbindlichen Begriffe. Private Trainernotizen bleiben klar von freigegebenen Spielernotizen getrennt.

- [x] Navigation, Einladungen, Kontoseite, Leerzustände, Erinnerungen und Fehlermeldungen sprachlich abgleichen. Gespeicherte eigene Inhalte und technische API-Schlüssel nicht umschreiben.
- [x] Gemeinsame Anzeigehilfen für Statuswerte, bekannte Messwertnamen und strukturierte Trainingsvorgaben einsetzen. Zahlen, echte Nullwerte und Testvorgaben unverändert erhalten; unbekannte eigene Texte erhalten und HTML weiter maskieren.
- [x] Bestehende Trainer-/Spieler-, Rollen-, Synchronisierungs- und Freigabeprüfungen ausführen; Formatierung gezielt prüfen. Mobiler Browser bei 320/390 Pixeln, echte isolierte PostgreSQL-Abnahme und unabhängiger Review erfolgreich. Der Veröffentlichungsstand wird im lokalen Abnahmestatus festgehalten.

Ausführung inline. Keine neue KI-Anfrage, Migration, Änderung von Rechten oder Trainingsregeln. Spieler erhalten weiterhin keine technischen Trainerpläne. KI-Texte werden nur für zukünftige Entwürfe auf die Du-Anrede festgelegt; erzeugte Entwürfe bleiben bis zur Trainerfreigabe privat.
